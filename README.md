# جودة إنشاء شبكة التوزيع الأرضية — TSC SP128

موقع تعليمي عربي (RTL) بملف واحد قابل للتشغيل مباشرة، مبني بـ HTML5 و CSS3 و JavaScript فقط، بدون أي مكتبات خارجية وبدون أي أكواد محرّر مواقع.

---

## 1) هيكل المشروع

```
se-site/
├─ index.html              ← المشروع كامل: البنية + التنسيق + السكربت (ملف واحد)
├─ README.md               ← هذا الملف
└─ assets/
   ├─ images/
   │  ├─ cover.jpg         ← الصورة الرئيسية (غلاف الكتاب)
   │  ├─ favicon.png       ← أيقونة الموقع
   │  ├─ model-fallback.jpg← الصورة البديلة عند عدم دعم الواقع المعزّز
   │  └─ gallery/          ← صور المعرض (page-24.jpg … page-175.jpg)
   ├─ models/              ← ضعي هنا ملفات المجسّمات ثلاثية الأبعاد بصيغة .glb
   ├─ audio/               ← ضعي هنا الملفات الصوتية (.mp3 / .ogg)
   └─ docs/
      └─ SP128.pdf         ← الكتاب الأصلي كامل بالصور والجداول
```

> ملاحظة: طلب التسليم كان «ملف واحد باسم index.html»، لذلك جُمعت CSS و JavaScript داخله.
> الملفات الثنائية (الصور والأصوات والمجسّمات وPDF) تبقى في `assets/` لأن دمجها داخل HTML
> يُبطئ التحميل بشكل كبير ويخالف قاعدة «ضغط الصور لتقليل زمن التحميل».

## 2) أين تُضاف الملفات؟

| النوع | المكان | كيفية الربط |
|---|---|---|
| صور المعرض | `assets/images/gallery/` | أضيفي عنصرًا في `SITE_DATA.gallery` داخل `index.html` |
| الصورة الرئيسية | `assets/images/cover.jpg` | تُستبدل بنفس الاسم مباشرة |
| مجسّم ثلاثي الأبعاد | `assets/models/cable.glb` | يُذكر المسار في بطاقة «المجسّم» وفي `assets/images/model-fallback.jpg` كبديل |
| ملفات صوتية | `assets/audio/name.mp3` | تُضاف بعنصر `<audio controls>` — **بدون تشغيل تلقائي** |
| ملف الكتاب | `assets/docs/SP128.pdf` | مضبوط في `SITE_DATA.links.pdf` |

### تعديل البيانات والروابط
كل النصوص والدروس والأسئلة والروابط موجودة في كائن واحد اسمه **`SITE_DATA`** في نهاية `index.html`.
الروابط غير المتوفرة مكتوبة بصيغة `[أضيفي الرابط هنا]`، وعند تركها كما هي:
- لا يظهر الزر أو يظهر كنص فقط،
- ولا يحدث أي خطأ في وحدة التحكم Console.

الروابط التي تحتاج استبدالًا:
```js
whatsapp:     "[أضيفي الرابط هنا]"   // مثال: https://wa.me/9665XXXXXXXX
video:        "[أضيفي الرابط هنا]"   // رابط تضمين فيديو
formEndpoint: "[أضيفي الرابط هنا]"   // وجهة استقبال نموذج التواصل
```

## 3) خطوات التشغيل محليًا

الطريقة الأسرع: افتحي `index.html` بالنقر المزدوج — الموقع يعمل مباشرة.

لتجربة أقرب للنشر (وضروري لملفات GLB والواقع المعزّز) شغّلي خادمًا محليًا:

```bash
# Python 3
cd se-site
python3 -m http.server 8000
# ثم افتحي: http://localhost:8000

# أو Node.js
npx serve .
```

## 4) خطوات النشر عبر HTTPS

### GitHub Pages
1. أنشئي مستودعًا **خاصًا** (الكتاب مصنّف داخليًا).
2. ارفعي محتويات المجلد كما هي في جذر المستودع.
3. Settings ← Pages ← Source: `Deploy from a branch` ← Branch: `main` / `root`.
4. ينتج رابط `https://<username>.github.io/<repo>/` بشهادة HTTPS تلقائية.

### Netlify
1. Add new site ← Deploy manually، واسحبي مجلد المشروع كاملًا.
2. Build command: (اتركيه فارغًا) — Publish directory: `.`
3. تُفعَّل شهادة HTTPS تلقائيًا من Let's Encrypt.

**نسخة احتياطية:** احتفظي بنسخة من المجلد كاملًا (أو أنشئي وسمًا `git tag v1`) قبل أي تعديل كبير.

## 5) الأجهزة والمتصفحات المدعومة

| البيئة | الحد الأدنى | الحالة |
|---|---|---|
| Chrome / Edge (كمبيوتر) | 90+ | دعم كامل شامل الواقع المعزّز على أندرويد |
| Firefox | 90+ | دعم كامل عدا WebXR |
| Safari (macOS) | 15+ | دعم كامل |
| Safari (iOS / iPadOS) | 15+ | دعم كامل، والواقع المعزّز عبر Quick Look عند إضافة ملف USDZ |
| Chrome أندرويد | 90+ | دعم كامل + WebXR AR |
| Samsung Internet | 15+ | دعم كامل |

`aspect-ratio`، `IntersectionObserver`، `fetch`، `details/summary`، و`prefers-reduced-motion`.

## 6) البدائل عند عدم دعم AR / VR / MR

- **الواقع المعزّز (AR):** يُفحص الدعم عبر `navigator.xr.isSessionSupported('immersive-ar')`.
  عند عدم الدعم تُعرض صورة ثابتة عالية الجودة مع وصف نصي كامل، وتظهر رسالة توضيحية للمستخدم.
- **الواقع الافتراضي (VR):** لا يُعرض زر النظارة إطلاقًا عند غياب الدعم، ويبقى المحتوى متاحًا
  كجولة صور داخل المعرض وشرح نصي.
- **الواقع المختلط (MR):** يعتمد الموقع على التصفح التقليدي (بطاقات، جداول، صور)، وكل معلومة
  متاحة نصيًا فلا يفقد الزائر أي محتوى.
- في جميع الحالات لا يظهر أي خطأ في وحدة التحكم Console.

## 7) إمكانية الوصول وسهولة الاستخدام

- اتجاه الكتابة من اليمين إلى اليسار `dir="rtl"` وخط عربي واضح (Tajawal).
- ثلاثة ألوان فقط: كحلي `#0E3A5C` + ذهبي `#C8A24A` + خلفية رمادية فاتحة `#F5F7FA`.
- أزرار بارتفاع 52 بكسل على الأقل، ومؤشرات تركيز واضحة للوحة المفاتيح.
- رابط «تخطّي إلى المحتوى»، وعناوين متدرّجة، ونصوص بديلة لكل الصور.
- احترام `prefers-reduced-motion` لإيقاف الحركات لمن يحتاج ذلك.
- لا نوافذ منبثقة مزعجة، ولا تشغيل تلقائي للصوت أو الفيديو.

---

## 8) الحماية والخصوصية

- نموذج التواصل يطلب حقلين إلزاميين فقط (الاسم والرسالة) ووسيلة تواصل اختيارية.
- الحماية من الرسائل المزعجة: حقل مخفي (Honeypot) + مؤقّت زمني 3 ثوانٍ + تحقق من الطول.
- لا يوجد أي بريد إلكتروني أو معلومات شخصية داخل الكود.
- لا ملفات تتبّع ولا إعلانات ولا تخزين محلي للبيانات.
